# Reusable Video Components

Read when selecting or implementing scene elements. Start with the consumer's approved
Figma/component library. Choose only elements the brief needs:

| Element | Inputs to resolve |
|---|---|
| Scene background | Approved surface and any permitted image, texture or effect |
| Title | Display font, hierarchy, safe area, copy and entrance/exit timing |
| Text highlight | Approved highlight component and emphasis style |
| Label or badge | Approved variant, spacing, text and icon |
| Logo | Approved vector/component, variant, clear space and minimum size |
| Content card | Approved frame, corner, border and shadow treatment |
| Lower third | Identity copy, contrast over footage and screen position |

Preserve component geometry, native vectors and editable text. Avoid adding borders or
shadows already contained in artwork. Fonts and colors are inputs, never defaults in a
shared example. Check selected frames for accidental inherited overlays or clipping.
