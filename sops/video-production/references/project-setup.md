# Project Setup

Read when creating a new code-based motion project. Use the current supported
scaffolding command and dependency versions for the selected engine; check its
primary documentation before installing. Keep work in the consumer's project path.

- Inspect an existing application before scaffolding a duplicate.
- Separate approved brand tokens, font configuration, reusable components and scenes.
- Load colors, typography, dimensions and optional effects from the resolved consumer
  sources; a sample scaffold's defaults are not approved brand values.
- Copy or link fonts only from licensed sources according to the consumer's policy.
- Reference approved logo files or component IDs. Do not redraw or invent variants.
- Set composition dimensions, frame rate and duration from the brief.
- Ignore previews, renders and sensitive footage in Git; record durable external links.
- Render a small representative scene before building the whole sequence.
