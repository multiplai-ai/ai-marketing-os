# LinkedIn profile

Treat the profile as the connection between a useful post and a relevant
business relationship. Make the audience, value, credibility, and next step
understandable without requiring visitors to decode internal terminology.

## Establish the assignment

Read the selected brand's positioning, audience, offer, approved evidence,
voice, visual identity, and destination inventory. Identify the profile owner
and whether this is a personal profile or a company page. Request current
profile text or retrieve the supplied profile with an available reader.
If it is unavailable, deliver a proposed structure and copy with current-state
assessment marked unavailable; do not describe unseen defects.

A company page does not have every personal-profile section. Use only controls
actually present. Check current platform capabilities if the recommendation
depends on an account feature, subscription, text limit, or image dimension.
Do not infer search-ranking benefits from keyword presence alone.

## Evaluate the visitor's path

For each relevant surface, compare observed material with the buyer's decision:

| Surface | Decision to support | Recommended treatment |
| --- | --- | --- |
| Banner | Is this relevant to me? | One readable value proposition, a small amount of usable proof, and a clear pointer. Preserve the selected brand identity; inspect phone-size readability if visual work is requested. |
| Headline | Who is this for, and what do they help with? | Audience, outcome or role, and concise verified credibility. Use language buyers recognize without promising keyword rankings. |
| Featured | What can I do next? | Offer paths for a new visitor, an interested reader, and a ready buyer. A useful resource, an owned-channel subscription, and an available service are examples, not mandatory assets. |
| About | Why this problem, this approach, this person? | An opening that earns attention, the buyer's problem, the offered work, relevant evidence, and a next step. Do not hide basic meaning just to induce a click. |
| Services | Can they solve my problem? | Select accurate categories and relevant testimonials when permitted and supported by the actual account. |
| Experience | Have they done work that matters here? | Accurate responsibilities and evidenced outcomes, with relevant permitted media or links. Distinguish employment from client work. |
| Other link/button | Where does this lead? | Verify the feature exists and that its destination matches the promise before proposing activation. |

Keep hierarchy clear when the brand serves more than one buyer. Use the shared
outcome in the headline and distinguish needs in About, offers, or destinations;
do not stuff every service into the first line. A logo, testimonial, title, or
number must be approved for the intended use, not merely present in a source.
If suitable evidence is missing, use a clear value statement without inventing
social proof.

## Return a reviewable pack

Include the observed source and capture date, the main conversion problem,
prioritized changes by section, proposed copy, and a destination table:
visitor need → promise → actual URL → readiness or missing input. Flag unavailable
assets and unverified claims beside the dependent copy. A workshop concept is
not a bookable offer; a proposed resource is not a downloadable asset.

For requested banner/card production, hand the approved message to the brand's
visual workflow with its visual sources and actual platform requirements.
Profile review does not require redesigning the entire brand.

Read the pack as one visitor journey: consistent buyer and offer, support for
claims, credible differentiation, and working next steps. Return useful drafts
with unresolved items visible. Account editing, publishing, subscription import,
and sending messages are not performed by this skill. Use `linkedin-post` for
feed copy and `linkedin-program` for the ongoing publishing/relationship plan.
