# Avatar Clips

Read only when the brief explicitly needs an avatar presenter. Motion graphics or
section cards alone do not imply an avatar. Check current HeyGen documentation and
available project controls before specifying a workflow or output capability.

Use the authorized presenter's identity, script and voice. Resolve background, font,
framing and logo treatment from the consumer's approved video brief. Test whether the
chosen output supports transparency or requires an opaque background; verify in the
actual editing application rather than assuming chroma key or alpha support.

Preview pronunciation, lip sync, framing, timing and consent scope. Match the clip to
the final edit and inspect skin tone and contrast before applying any color treatment.
Do not apply a brand-colored grade to a person by default. Keep generated files in the
consumer's approved media storage and record the source project and export settings.
