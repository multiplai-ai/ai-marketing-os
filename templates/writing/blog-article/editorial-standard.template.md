# Blog/article editorial standard

The piece makes one source-supported argument for a named audience. It uses concrete evidence, attributes external facts, preserves unresolved claims in frontmatter, and makes no invented firsthand claims. Sections build an argument instead of filling a template. The opening earns attention through substance. The ending advances the reader to a useful action without summarizing the article in a bow. Run the human-writing gate and then conduct a read-aloud, voice, sensitivity, and destination-message-match review.
